📖 私たちについて

黄泡泡短劇は、若者向けに作られた高品質な縦型ショートドラマのオンライン視聴プラットフォームです。ファンタジー、都市サスペンス、逆転劇、学園青春、甘い恋愛など、多様なジャンルの人気ショートドラマを豊富に取り揃えています。

「無料オンライン視聴、タップしてすぐ再生、次々と見られる」というスムーズな体験を提供します。PCブラウザでもスマートフォンでも、いつでもどこでも没入感のあるドラマ視聴を楽しめます。

✨ 主な特徴

📱 マルチデバイス対応: Androidアプリのダウンロードに対応。iPhoneやPCユーザーはウェブ版から直接スムーズに視聴可能。視聴履歴は自動的に同期されます。

🎬 豊富なジャンルと毎日更新: 厳選された高品質なコンテンツ。必ずあなたを「夢中」にさせる作品が見つかります。

⚡ タップして即再生、縦型没入感: モバイル向けに最適化された縦型再生。上にスワイプするだけで次の作品に切り替わります。

🤝 ストーリーの共創: 視聴者は制作陣が提起するストーリーの展開に関する議論に参加できます。最も「いいね」を集めたアイデアは、今後の台本に採用される可能性があります！
